# Сеть детских садов «ЗАЙКА» в Алматы 🐰✨

Официальный промо-сайт сети детских садов «ЗАЙКА» в г. Алматы.

## 🌟 Основные особенности
- **5 филиалов в Алматы**: ул. Ходжанова 5В (ЖК Rams Luxury), ул. Кожамкулова 149, ул. Маркова 9, ул. Аманжол 6 (Мамыр), мкр-н Баянауыл 56.
- **Интерактивная карта филиалов (Яндекс.Карты API)** с геометками, переключением филиалов, карточками и прямым построением маршрута в 2GIS / Яндекс.
- **Реальные отзывы 2ГИС (Рейтинг 4.9 ★)**: анимированная бесконечная горизонтальная лента с автопрокруткой, паузой при чтении и ручным перелистыванием (кнопки, drag мышью, touch-свайп).
- **Государственная субсидия DamuBala**: 50 000 ₸/мес на каждого ребенка.
- **Тематический визуальный стиль Sun School**: фирменная палитра, авторский 3D-маскот Зайка, фото филиалов и преимуществ.
- **Полная адаптивность**: качественная поддержка смартфонов, планшетов и десктопов.
- **Интерактивный калькулятор стоимости** и модальные окна записи на экскурсию в WhatsApp / телефон.
